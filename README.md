# pydev_template_ai_enabled

This repository provides a preconfigured Python development environment for GitHub Codespaces, including AI-assisted tools (GitHub Copilot, Copilot Chat and Anthropic Claude), Spec-Kit CLI, and support for Model Context Protocol (MCP) servers.

See the included `.devcontainer`, `.vscode`, `.mcp`, `.env.example` and `.gitignore` files for configuration details.
